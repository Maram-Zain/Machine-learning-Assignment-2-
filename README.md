# Customer Personality Analysis - ML Assignment 2

This project applies Supervised and Unsupervised Machine Learning techniques on the Customer Personality Analysis dataset to segment customers and predict their behaviors.

## Project Structure
* `Customer_Personality_Analysis.ipynb`: The main Jupyter Notebook containing data preprocessing, regression, classification, and clustering.
* `requirements.txt`: List of required Python packages.

## How to Run
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Open and run the notebook in Google Colab
